# Multi-Brand Email Signature Generator

A modern, dynamic email signature generator built for Cozmo Travel and its subsidiary brands.

## Features
- Generates high-quality, pixel-perfect HTML email signatures without external stylesheets.
- Dynamic responsive brand buttons to switch between subsidiaries (e.g. Cozmo, Cozmo Logistics, Cozmo Hub).
- Admin controls to manage brands, logos, banners, and office locations.
- Single-click copy support for Outlook and Apple Mail.
- Fully local execution (no backend required).

## Local Development
Run a local Python web server:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser.
